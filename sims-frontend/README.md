**SIMS (Student Information Management System)** frontend client developed for the **Ministry of Education, Yemen - Hadhramaut Coast Branch**. 
This user interface provides a modern, responsive, and intuitive dashboard built with **React**, **TypeScript**, and **Tailwind CSS**, designed to consume the SIMS Laravel RESTful API and handle complex administrative workflows seamlessly.

---

## ✨ Key Features

- **⚡ Modern Tech Stack:** Powered by Vite for lightning-fast bundling and HMR.
- **🛡️ Secure Authentication:** Token-based authentication integration with Laravel Sanctum.
- **📊 Interactive Dashboards:** Dynamic statistical widgets and data management tables.
- **🧑‍🎓 Student & Academic Management:** Clean UI components for handling students, classes, levels, and school transfers.
- **📄 Official Documents & Reports:** Seamless generation and preview of official certificates and student reports.
- **🎨 Responsive & Sleek UI:** Styled meticulously using Tailwind CSS with custom component libraries.

---

## 🛠️ Tech Stack

- **Core Framework:** React 19, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios (or Fetch API for backend communication)
- **Routing:** React Router

## 🚀 Installation & Local Setup

Follow these steps to set up and run the frontend client locally:

### 1. Prerequisites
Ensure you have Node.js & NPM installed on your machine.

### 2. Clone/Navigate to Frontend Directory
Make sure you are inside the frontend folder of your Monorepo structure:
```bash
cd sims-system/sims-frontend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run the Development Server
```bash
npm run dev
```
The application will be accessible at: http://localhost:5173 (or the port specified in your terminal).
